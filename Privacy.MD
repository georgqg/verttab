# Политика конфиденциальности / Privacy Policy

Дата вступления в силу: 21 октября 2026

## Что делает расширение

VertTab — расширение для Google Chrome, которое открывается в боковой панели браузера и позволяет работать с Google Задачами (Google Tasks) прямо из браузера.

## Какие данные обрабатываются

- **Данные Google Задач.** Для работы расширения ему нужен доступ к вашим задачам в Google Tasks (область доступа `https://www.googleapis.com/auth/tasks`). Расширение читает и изменяет задачи только по вашему действию внутри боковой панели.
- **OAuth-токен.** Токен доступа, полученный через вход в Google, хранится локально в браузере средствами Chrome. Он используется только для запросов к Google Tasks API.

## Что расширение НЕ делает

- Не передаёт ваши данные, задачи и токены на сторонние серверы, в аналитику или рекламные сети.
- Не продаёт и не передаёт данные третьим лицам.
- Не использует данные для показа рекламы.

## Хранение данных

Все настройки и кэш хранятся локально в браузере. Удалить их можно, удалив расширение или очистив данные сайта в настройках Chrome. Отозвать доступ расширения к вашему аккаунту Google можно на странице https://myaccount.google.com/permissions.

## Использование данных Google

Использование информации, полученной через API Google, соответствует [Политике использования данных пользователей API Google](https://developers.google.com/terms/api-services-user-data-policy), включая требования ограниченного использования.
