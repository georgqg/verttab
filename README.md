# VertTab

Расширение для Google Chrome: боковая панель с Google Задачами (Google Tasks).

## Возможности

- Просмотр и управление задачами Google Tasks из боковой панели Chrome.
- Работа без отдельной вкладки: панель открывается рядом с текущей страницей.

## Установка (для разработки)

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `dist/`.

## Доступ к данным

Расширение запрашивает доступ к Google Задачам (`https://www.googleapis.com/auth/tasks`). Подробности о том, какие данные обрабатываются и как они хранятся, — в [политике конфиденциальности](PRIVACY.md).
